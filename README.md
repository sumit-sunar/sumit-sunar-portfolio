# Sumit Sunar Portfolio

This is the personal portfolio website for Sumit Sunar, a front-end developer based in Nepal. The site showcases his skills, projects, and contact information with a clean responsive design and SEO-friendly metadata.

## Project structure

- `index.html` – main portfolio page and SEO metadata
- `assets/css/styles.css` – styling and responsive layout
- `assets/js/main.js` – navigation, dark mode, contact form, and animations
- `assets/img/` – images and icons used in the portfolio

## Run locally

Open `index.html` in a browser, or serve the folder with a simple local server such as:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
